Install on AndroidInstaller sur Android

  1. Tap Download for Android and wait for the file to finish.Touchez Télécharger pour Android et attendez la fin du téléchargement.
  2. Open the downloaded ARTIK-Android.apk (in Downloads or the notification).Ouvrez le fichier ARTIK-Android.apk (dans Téléchargements ou la notification).
  3. If asked, allow Install unknown apps for your browser, then go back.Si demandé, autorisez Installer des applis inconnues pour votre navigateur, puis revenez.
  4. Tap Install, then Open. Done!Touchez Installer, puis Ouvrir. C’est fait !

Android warns about apps that don’t come from the Play Store. That is normal for direct downloads. ARTIK is always signed with the same ARTIK key, so updates install over it. Small updates arrive inside the app by themselves.Android avertit pour les applis qui ne viennent pas du Play Store. C’est normal pour un téléchargement direct. ARTIK est toujours signée avec la même clé ARTIK, donc les mises à jour s’installent par-dessus. Les petites mises à jour arrivent toutes seules dans l’appli.
